# PS3 streaming reference

Courtesy source snapshot for a PS3-to-Moonlight streaming project. Specific to the original build; unmaintained and not intended as a reusable project or supported setup.

- `sunshine/`: Sunshine 2025.924.154138 integration patch and Magewell capture/encoding backend.
- `relay/`: Python input/Guide-button relays, UART helper, and USB controller profiles.
- `firmware/`: Pico 2 UART-to-USB firmware and build helpers.
